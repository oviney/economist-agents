## Why you are reading this

B-040 Phase 2 is a gate no agent can clear for you: these cases were drafted by an agent to calibrate a judge of its own model family, so the set needs a control outside that loop. Tick `agree` where the labelled verdict is right, `disagree` where it is not. A disagreement is a finding, not a failure — a mislabelled ground-truth case is worse than a missing one (README rule 3).

**Negatives are listed first** because they are the half an agent is most likely to have got wrong: a positive is drawn from a recorded defect, whereas a negative asserts that nothing is wrong, which is the harder claim to check.

### 4. `g2-projection-reported-as-a-projection`

**Gate G2** · labelled **pass** · source: `the-ai-testing-paradox`

**Why it is labelled `pass`:** A NEGATIVE case. ### 8. `g3-percentage-breakdown-sums`

**Why it is labelled `pass`:** A NEGATIVE case, and a harder G3 pass than the arithmetic alone suggests, because it has two independent checks and both hold.
