# B-045 · Docs-truth gate — fail `ci-local` on a broken doc reference

**Status:** APPROVED — owner LGTM 2026-09-01
**Date:** 2026-08-31
**Backlog:** B-045

## Problem

Instruction documents in this repo reference files that do not exist. The
documents are how a human or an agent learns to operate the repo, so a dangling
path is not cosmetic — it is an instruction to open a file that was deleted,
moved, or never existed.

Three such contradictions were found *by hand* in the previous session and
fixed on `fix/claude-md-hero-contradiction`. Hand-finding does not scale and
does not survive a cleared session. There is no GitHub Actions CI (ADR-0015);
`make ci-local` is the only merge gate, and it has no check for this.

## Two findings that invalidate parts of the prior implementation

The prior implementation on `b024-retire-paid-path-STALE-BASE` is a source to
port from, not to cherry-pick. Two of its premises are false on this base:

1. **`ALLOWED_MISSING` must start empty.** Its single entry excuses
   `scripts/economist_agent.py` as "deleted by B-024". B-024 was abandoned
   (stale base); the file exists on `main` at 49,307 bytes. Carrying that entry
   forward would suppress a check on a live file.
2. **Its docstring is misattributed** — it cites B-025 and B-024's
   13,863-line deletion, neither of which landed. Rewritten for B-045.

Also verified, because it looked like a blocker and is not:
`.github/copilot-instructions.md` carries a "do not hand-edit — regenerated by

below `GENERATED_HEADING = "## Learned Anti-Patterns"`, and that heading does

Editing them is safe and will not be regenerated away.

**Out:**
- **Truth of prose.** This gate checks that a referenced path *exists*, not
  that what the document says about it is *true*. It would not have caught
  either fix on `fix/claude-md-hero-contradiction` — both named files that
  exist while describing behaviour that had been deleted. Stated here so the
  gate is not mistaken for more than it is.
- **History.** `docs/archive*/`, `docs/sprint_logs/`, `docs/CHANGELOG.md` and
  `docs/adr/*` record what was true when written. A gate that forces edits to
  history to satisfy a linter is worse than no gate.

  paths do not exist on a clean checkout and would report as breaks for anyone
  who has not run the pipeline.

## Design

`scripts/check_docs_references.py`, exit 0 clean / 1 with a list.

- **Documents scanned** — an explicit tuple, not a glob, so adding one is a
  deliberate act: `CLAUDE.md`, `README.md`, `CONTRIBUTING.md`,
  `copilot-instructions.md`, `.github/copilot-instructions.md`,
  `docs/keyless-pipeline-runbook.md`. A listed document that is itself missing
  is a break.
- **References extracted** from backtick spans and markdown link targets.
- **Scannable prefixes** — `scripts/ src/ tests/ docs/ agents/ mcp_servers/
  .github/`. Anything else is prose or generated output.
- **Rejected before checking** — anything containing `<>*{}$?!|"'()[]~,` or a
  space (prose, templates, call expressions); URLs; `#`/`mailto:` anchors.
- **Stripped before checking** — a trailing `:123` line citation, and a
  trailing `#L12-L34` GitHub anchor *(the known bug; carries a regression test)*.
- **Relative resolution** — only `./` and `../` resolve against the referring
  document's directory. An earlier version resolved every token that way and
  turned `` `ANTHROPIC_API_KEY` `` into `docs/ANTHROPIC_API_KEY`, producing 95
  false positives. A gate that noisy gets switched off.
- **`ALLOWED_MISSING`** — starts empty. Every entry requires a non-blank reason;
  a blank one raises, because an unexplained entry is indistinguishable from rot.

## Acceptance criteria

1. `python scripts/check_docs_references.py` exits 0 on a clean tree.
2. Introducing one dangling reference into any scanned document makes it exit 1
   and name the document, line, and path.
3. `make ci-local` fails on that broken reference and passes once reverted.
4. All three `#L` anchor references resolve, guarded by a regression test.
5. Coverage does not drop below the 70% floor.
6. `BACKLOG.md` records 10 real breaks, not 13.

## Boundaries

- **Ask first** before adding any entry to `ALLOWED_MISSING` — the whole point
  is that suppression is deliberate and justified.
- **Ask first** before widening `SCANNABLE_PREFIXES` or the document list.
- Do not edit anything under `docs/archive*/`, `docs/sprint_logs/`,
  `docs/CHANGELOG.md`, or `docs/adr/*`.
- No new dependency. Standard library only.

## Errata

- The prior implementation's first version resolved every backticked token
  against the doc directory → 95 false positives. Do not reintroduce.
- `data/` was nearly added as a scannable prefix with an allowlist entry to
  paper over the resulting failures. It is gitignored; it stays out.
- Two rounds of grep-based "this is unreachable" reasoning were overturned in
  this repo. Before claiming a file is unused, run it.
